## このスキルを用いて行うこと

"pr-review スキルを利用したコードレビューを実施してください"というプロンプトで、サブエージェント（context fork無し）を起動してください。
起動前に、どのタイプ（名前）のエージェントを起動するのか報告してください。
サブエージェントの起動後は、レビューが完了するまで待機し、レビューの完了後にレビュー結果のサマリーを報告してください。
サブエージェントが起動してから、レビューが完了するまで高頻度の進捗報告は不要です。 最長5分のブロックを許容します。
エージェントの起動前とレビュー完了後に時刻を記録し、レビューにかかった時間をサマリーと共に報告してください。

## サブエージェントの起動方法

使えるツールに応じて、次のいずれかで起動してください。

- Claude の Agent ツールが使える場合: `subagent_type: agent-skills:lead-reviewer` を指定してください。`name` は指定しないでください（指定すると、環境によってはチームの一員として起動し、レビュー結果を返さずに待機の通知だけを送ります）
- Codex の `spawn_agent` が使える場合: `lead_reviewer` エージェントを指定し、`task_name` を渡してください
- どちらも使えない場合: サブエージェントを起動せず、あなた自身が pr-review スキルを実行してください

レビュー結果は、サブエージェントの応答本文で受け取ってください。
